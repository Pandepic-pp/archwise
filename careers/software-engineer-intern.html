Software Engineer Intern

Engineering Closed Remote · Internship

Work directly with the founding team building the AI interview platform end-to-end — from the real-time voice interview flow to the evaluation pipeline.

Responsibilities

  • Ship features across the frontend (React/TypeScript) and backend (Node/Express/MongoDB)
  • Work on the real-time interview flow, including audio streaming and AI evaluation
  • Write clean, tested code and participate in code review
  • Debug production issues and help improve system reliability

Requirements

  • Comfortable with JavaScript/TypeScript and at least one modern web framework
  • Understanding of REST APIs and relational or document databases
  • Currently pursuing or recently completed a degree in CS or a related field
  • Strong communication skills and a bias toward shipping

Nice to Have

  • Experience with React, Node.js, or MongoDB specifically
  • Familiarity with WebSockets or real-time systems
  • Interest in AI/LLM-powered products
